# assets 目录说明

本目录用于存放**赞赏码图片**（可选），供收尾闭环生成的「投递汇总.html」内嵌展示。

## 如何使用

将你的收款码图片按以下文件名放入本目录：

| 文件名 | 说明 |
|--------|------|
| `tip_wechat.jpg` | 微信赞赏码 |
| `tip_alipay.jpg` | 支付宝赞赏码 |

> ⚠️ **隐私提醒**：赞赏码是个人收款码，属于敏感信息。本仓库**默认不包含**这两张图片（已加入 `.gitignore`）。如需使用打赏功能，请自行放入上述文件，切勿将真实收款码提交到公开仓库。

## 无图片时的表现

脚本已做优雅降级：若 `tip_wechat.jpg` / `tip_alipay.jpg` 不存在，「投递汇总.html」的二维码区域会留空，仅做文字提示，不会报错。功能不受影响，打赏为完全自愿。
